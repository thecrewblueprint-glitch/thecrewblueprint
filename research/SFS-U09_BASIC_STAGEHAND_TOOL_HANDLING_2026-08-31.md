# SFS-U09 — Basic Stagehand Tool Recognition, Handoff and Storage

**Prepared:** 2026-08-31  
**Status:** Source packet complete for recognition/readiness/handoff boundaries; no dangerous/powered/cutting-tool procedure is authorized by this packet  
**Domain:** Stagehand/general-hand practical evidence  
**Course-format decision:** Deferred

## Research question

What can The Crew Blueprint responsibly teach a new stagehand about common call-specific hand-tool expectations, tool recognition, inspection, controlled handoff and storage without teaching hazardous cutting/powered/specialist procedures or implying that carrying a tool authorizes the worker to perform every task associated with it?

## Bottom-line finding

Multiple IATSE locals publish basic tool expectations for stagehands, and those lists vary by local, venue, department and assignment. That supports teaching a **tool-readiness mental model**, not one universal mandatory national tool kit.

A beginner can be taught to:

- check call/employer/local requirements;
- recognize common basic hand-tool categories;
- keep tools in serviceable condition;
- keep them organized/identified;
- hand tools to another worker deliberately rather than tossing/leaving them uncontrolled;
- return/store borrowed tools;
- ask before using an unfamiliar tool or performing an unfamiliar task;
- understand that department-specific and overhead/specialist work adds requirements and authorization boundaries.

This packet intentionally does **not** teach cutting techniques, powered-tool operation, electrical testing, rigging-tool procedures or work-at-height tool use.

## Evidence

### 1. Tool expectations vary by call and department

IATSE Local 118 publishes a basic stagehand tool list and explicitly notes that other departments may have additional requirements and that workers should check ahead of the call.

Source:
- IATSE Local 118 — Stagehand Tools  
  https://iatse118.com/page/stagehand-tools

Local 118's new-hire FAQ likewise tells workers to bring required PPE and a basic hand-tool kit, with additional tools depending on the job/employer.

Source:
- IATSE Local 118 — FAQ for New Hires  
  https://www.iatse118.com/faq/new-hires-before-your-first-shift

IATSE Local 50 states that a basic tool package is required for every job and department-specific tools are added depending on assignment.

Source:
- IATSE Local 50 — Required Tools  
  https://iatse50.org/work-policies/tools/

IATSE Local 31's first-day guidance similarly distinguishes basic items from venue/convention additions and states that some safety gear or additional tools are required only on certain calls.

Source:
- IATSE Local 31 — What to Bring Your First Day  
  https://www.iatse31.com/library/what-to-bring-your-first-day/

Curriculum implication:

Do not publish one Crew Blueprint list as “the required stagehand toolkit everywhere.” Teach learners to check the controlling call requirement.

### 2. Knowing a tool is not the same as being authorized to use it for every task

Local 50 separates a basic package from department-specific electrical/sound and carpentry/props/fly additions. This is evidence that tool expectations track assignments and departments.

Source:
- IATSE Local 50 — Required Tools  
  https://iatse50.org/work-policies/tools/

Curriculum implication:

A learner may recognize a tool without being authorized, qualified or competent to perform every task that tool can be used for. Electrical testing, rigging, overhead work, powered equipment, cutting and repair procedures require their own scope/training/authority.

### 3. Ask when uncertain

IATSE Local 98 explicitly instructs stagehands to ask questions when they are unsure about a job assignment and to report to the appropriate steward/department head.

Source:
- IATSE Local 98 — Job Basics  
  https://www.iatse98.org/job-basics

Local 31 also tells new workers to ask questions and not attempt tasks they are unsure how to perform.

Source:
- IATSE Local 31 — What to Bring Your First Day  
  https://www.iatse31.com/library/what-to-bring-your-first-day/

This strongly supports a stop/ask boundary in any tool-related lesson.

## Transferable learner outcome

A bounded beginner outcome can be:

1. read the call requirements before choosing tools/PPE;
2. recognize a small set of common non-powered hand-tool categories used on stagehand calls;
3. visually check a tool for obvious damage or missing parts before handling it;
4. keep personal tools organized and identifiable;
5. carry/store tools so they are not abandoned in aisles, on equipment or in uncontrolled work areas;
6. use a deliberate verbal/physical handoff when passing tools;
7. return borrowed tools and report damage/loss;
8. ask before using an unfamiliar tool or doing an unfamiliar task;
9. recognize when a task belongs to a department/specialist or requires separate employer training.

## Explicit exclusions

This packet does not teach:

- cutting-tool technique;
- powered-tool operation;
- electrical meters/testing;
- rigging hardware/tool procedures;
- tool use while climbing/working overhead;
- improvised tool substitution;
- repair/service work;
- one universal tool list.

Those subjects require separate authority/safety analysis and, where appropriate, direct employer/in-person instruction.

## Visual evidence needs

Future learner visuals could safely focus on:

- labeled examples of basic non-powered tool categories;
- damaged-versus-serviceable visual inspection examples;
- organized pouch/bag versus tools left in work paths;
- deliberate handoff versus uncontrolled placement;
- decision graphic: `recognize` → `assigned?` → `trained/authorized?` → `use or ask`.

Do not use visuals that teach hazardous cutting, energized testing or other dangerous operational technique.
