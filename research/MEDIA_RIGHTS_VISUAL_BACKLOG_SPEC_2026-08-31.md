# Media Rights Register and Visual Production Backlog

**Prepared:** 2026-08-31

## Problem

The normalized curriculum currently has far more learner routes than reviewed visual evidence. Physical production learning needs recognition imagery, diagrams, documents, and bounded demonstrations; visual scale must not outrun rights/provenance control.

## Required MEDIA fields

For every meaningful image/video/diagram:
- media ID;
- file/route location;
- visual type;
- course/claim supported;
- creator/rightsholder;
- license/permission basis;
- source/provenance;
- AI-generation/edit status where applicable;
- depicted brand/model/system context;
- people/model-release status if identifiable people appear;
- venue/location permission if relevant;
- accessibility text alternative/caption/transcript;
- safety criticality;
- technical reviewer/date;
- release state;
- superseded-by link when replaced.

## Visual priority order

### P0 — beginner recognition
- road cases/casters/handles and safe parking state;
- common non-powered carts/dollies;
- cable families and ownership labels;
- stage directions/venue zones;
- work-area reset examples;
- dock/warehouse pedestrian zones;
- ready / damaged / quarantine state examples.

### P1 — system maps
- lighting power-vs-data conceptual flow;
- DMX/RDM/network layers;
- audio source-to-destination signal flow;
- console/bus/matrix mental model;
- video source/router/processor/display path;
- staging/scenic lifecycle and ownership map;
- PM advance/change/closeout loop;
- employer-overlay evidence-state model.

### P1 — document literacy
- sample pull list;
- case label/state card;
- discrepancy report;
- labor call plan;
- responsibility matrix;
- change log;
- show-day issue log;
- closeout/postmortem.

### P2 — short demonstrations
Only ordinary, bounded tasks supported by evidence and reviewed for safety. Hazardous specialist operations remain external.

## Release rule

No safety-critical sequence becomes authoritative solely because it looks plausible. Rights, model context, text fallback, and technical review must be recorded before promotion.
