# Stagehand Core — Call-Cycle Crosswalk

**Prepared:** 2026-08-31  
**Status:** Architecture crosswalk for research/curriculum build  
**Purpose:** Map current Stagehand Fundamentals and existing/new Field Skills into the revised linear Stagehand Core call lifecycle, identify duplication, and expose missing beginner instruction before live curriculum changes.

## 1. Controlling learner journey

> **Prepare → Arrive → Check in → Orient → Get assigned → Do the task well → Verify/handoff → Find the next task → Remain available / take directed breaks → Repeat → Strike/load out → Final handoff → Release → Clock out → Grow**

Every physical task uses the reusable loop:

> **Receive → Confirm → Inspect → Plan → Execute → Protect → Verify → Hand off → Reset → Seek next assignment**

### Arrive / Check In

Existing partial coverage:

- 1.3 Crew, Direction & Value
- 4.1 Orient First
- 5.1 Clarity First
- 5.2 Confirm & Report

**Major gap:** check-in is present as practice/evidence across the corpus but not yet a sufficiently explicit learner stage.

New learner-facing content should teach:

- find the correct entrance/check-in point;
- identify the person/process controlling the call;
- check in with the designated steward/lead/crew chief/house/department authority;
- confirm department/work group;
- understand where to place personal items/tools;
- do not independently begin touching visible equipment because nobody has assigned you yet;
- employer/local/venue check-in systems vary.

### Orient

Existing strong coverage:

- 4.1 Orient First
- 4.2 Read the Space
- 4.3 Hazard Recognition
- 9.1 Physical Support vs. Technical
- 9.2 Permission Levels
- 9.3 Classification Practice

Enhancement:

Turn orientation into a visible first-workflow scan:

- where am I supposed to be;
- who controls me;
- what is moving;
- where are the routes/exits;
- what work is overhead/energized/powered/restricted;
- where is gear being staged;
- where do I stay out of the way.

### Get Assigned

Existing partial coverage:

- 1.3 Crew, Direction & Value
- 5.1 Clarity First
- 5.2 Confirm & Report
- 6.1 The Sequence
- 7.1 Recognize It

**Major gap:** assignment receipt should become an explicit reusable method.

New assignment checklist:

1. Who gave me the task?
2. What am I handling/building/moving?
3. Where is it going?
4. Who owns the equipment/result?
5. Is it released/ready for me?
6. Who am I working with?
7. What sequence matters?
8. What should make me stop and ask?
9. What does “done” look like?

### Verify / Hand Off

Existing partial coverage:

- 5.2 Confirm & Report
- 6.4 Load-In Integration
- 7.2 Check It
- SFS-U04
- SFS-U05

**Major gap:** the course should explicitly teach that completing the physical motion is not always completing the assignment.

Required learner behavior:

- compare result to the stated acceptance condition;
- tell the responsible person if something is wrong/missing/damaged;
- return control to the equipment/system owner where final acceptance belongs to them;
- do not silently leave an incomplete task.

### Find the Next Task

Existing weak/implicit coverage:

- 5.2 Confirm & Report
- 5.3 Professional Presence
- Module 10 reputation/callback material

**Major gap:** this should be explicit.

Teach:

> When your assigned task is actually complete, return to the established work source — lead, steward, crew chief, department/work group or other call-specific process — and make yourself available for the next legitimate assignment.

Do not teach:

- wander into another department and start touching gear;
- create a task without authority;
- hide because the first task ended;
- perform “busy work” that interferes with the plan.

### Standby / Downtime / Breaks

Existing coverage: **insufficient**.

This becomes a new explicit beginner section.

Teach the distinction among:

- task complete and waiting for reassignment;
- production dependency/hold;
- standby;
- authorized break/meal period;
- show-call waiting;
- actual release from the call.

Core principle:

> **When there is work, do the work well. When the task is complete, become available for the next work. When production is waiting, wait professionally.**

Break timing, meal periods, standby rules and pay/timekeeping vary by employer, local/CBA, venue, production and jurisdiction. The course should teach learners to follow the controlling call rules rather than invent one national schedule.

### Repeat

The task loop repeats until the work phase changes.

This should be visualized as:

**Assignment → Task → Verify/Handoff → Next Assignment**

with side branches for:

- stop/escalate;
- dependency/hold;
- directed break;
- changeover;
- phase transition.

### Show Call / Changeover

Existing coverage:

- 1.2 The Shape of a Call
- 3.3 Phase Transitions
- scattered department/communication material

Gap:

Add beginner orientation to timing-sensitive work, waiting for cues, remaining available, quiet/clear backstage behavior where applicable, and not touching show-critical systems without assignment.

### Strike / Load Out

Existing strong coverage:

- 8.1 Strike Discipline
- 8.2 Fatigue & Urgency
- 8.3 Finish Strong
- current Field Skills repeat here under strike conditions

Enhancement:

Make the same universal task loop visible during load-out:

**release → gather/strike → protect/pack → route → case/truck destination → verify/handoff → next task**.

### Final Handoff / Release / Clock Out

Existing partial coverage:

- 8.3 Finish Strong
- 5.2 Confirm & Report
- 10.2 Reputation Patterns

**Major gap:** release and clock-out should be explicit and distinct from “my task is done.”

Teach:

- finish assigned closeout work;
- report unresolved damage/missing items/issues;
- return tools/equipment as directed;
- confirm crew/department release through the controlling process;
- follow the actual employer/local/venue timekeeping procedure;
- do not simply leave because personal work appears finished;
- know how to raise a time-record discrepancy through the appropriate process.

### Grow

Existing strong coverage:

- 10.1 Getting Hired
- 10.2 Reputation Patterns
- 10.3 Into Specialization
- 10.4 Early Calls & Beyond

Updated career message:

> Doing ordinary work reliably is what creates opportunities to receive more varied assignments, spend time with departments, gain supervised experience and eventually pursue technical, specialist, leadership or management pathways.

Avoid promising callbacks/promotion as a guaranteed result.

## 4. What should move versus remain

### Remain as cross-cutting principles

- Safety Mindset
- Department ownership/permission boundaries
- Communication
- PPE/readiness

These should be available at their original learner point but referenced throughout the call cycle rather than duplicated in every task.

### Move deeper practical instruction into skill modules

General explanations in Load-In and Tools/Gear should introduce the universal task loop. Detailed physical instruction belongs in the visual skill modules so it is not repeated inconsistently.

### Add explicit new call-cycle content

Priority gaps:

1. Arrival/check-in process.
2. Assignment receipt/confirmation.
3. Task completion versus handoff/acceptance.
4. Task complete → seek next assignment.
5. Standby/downtime/break distinctions.
6. Show-call/changeover beginner behavior.
7. Final release versus task completion.
8. Clock-out/timekeeping boundary.

## 5. Proposed Stagehand Core part structure

This supersedes the current four-part navigation architecture for the future Stagehand Core build while preserving all current lesson IDs/source lineage during migration.

### Part 1 — Show Up Ready

Current Modules 1–3, edited/crosslinked for direct transition into arrival.

### Part 2 — Arrive, Check In & Find Your Place

Current Module 4 + relevant Module 5/9 material + new explicit check-in/crew-assignment content.

### Part 3 — Get the Assignment & Work It

Relevant Modules 5–7 + universal task loop.

### Part 4 — Beginner Field Skills

Visual task library embedded in the progression. All ordinary beginner practical tasks live here; context is metadata, not seniority.

### Part 5 — Finish, Hand Off & Find the Next Task

New explicit work-cycle material + SFS-U04/U05 concepts.

### Part 6 — Breaks, Standby, Show Rhythm & Changeovers

New explicit material plus call-phase content from Modules 1/3/5.

### Part 7 — Load Out, Finish Strong & Get Released

Current Module 8 + explicit final handoff/release/timekeeping material.

### Part 8 — Build a Reputation & Choose Your Next Direction

Current Modules 9–10 as appropriate, with department/career launchpad.

## 6. Migration constraints

- Preserve all current canonical module/lesson IDs during source migration until redirects/matrix mappings are verified.
- Do not delete current Fundamentals or Field Skill routes during the initial Stagehand Core build.
- Reuse existing source relationships; do not treat moved text as newly sourced merely because its position changed.
- Keep knowledge completion, observed task practice, employer authorization and external qualification separate.
- Do not create universal break/pay/timekeeping rules from local practice.
- The eventual dashboard should follow the accepted compact Stagehand Fundamentals visual pattern.

## 8. Decision

The existing curriculum does **not** need to be discarded. It needs to be reorganized around how work actually happens.

The new Stagehand Core should teach a worker to think:

> **I showed up ready. I checked in. I know where I belong. I understand my assignment. I do it correctly. I finish and hand it off. I look for the next task. If there is nothing ready, I stay available. I take breaks when the call says to. I repeat until strike is done. I get released. I clock out correctly. Then I come back and do it better next time.**
