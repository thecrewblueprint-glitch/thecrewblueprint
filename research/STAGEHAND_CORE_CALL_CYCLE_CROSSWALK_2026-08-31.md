# Stagehand Core — Call-Cycle Evidence Crosswalk

**Prepared:** 2026-08-31  
**Status:** Evidence-gap map; not final curriculum architecture  
**Purpose:** Use the observable life cycle of a stagehand call to test whether current research covers the real work, while deferring all final decisions about course structure, sequencing and navigation.

## 1. Research lens

Use this working call cycle to expose evidence gaps:

> **Prepare → Arrive → Check in → Orient → Get assigned → Perform task → Verify / hand off → Seek next assignment → Standby / directed break / show wait → Repeat → Strike / load out → Final handoff → Release → Timekeeping → Career growth**

Use this working task loop to test individual practical topics:

> **Receive → Confirm → Inspect → Plan → Execute → Protect → Verify → Hand off → Reset → Seek next assignment**

Both are Crew Blueprint analytical models until source comparison justifies stronger language.

## 5. Controlled-work boundaries that require separate research tracks

Do not infer practical permission from general-stagehand frequency.

- overhead rigging and hoists → Rigging research/qualification track;
- energized temporary power → Electrics/production-power track;
- forklift/PIT and MEWP operation → employer/external training and authorization track;
- automation machinery → specialist track;
- special effects → awareness/regulatory/specialist track;
- regulated transport/cargo acceptance → logistics/driver/load-lead authority track.

The general-stagehand corpus should still research recognition, interfaces, pedestrian awareness, stop conditions and career pathways.

## 6. Evidence questions exposed by the call-cycle lens

The following questions should be answered before curriculum restructuring:

1. What check-in structures are common across union, labor-provider, venue, touring, corporate and festival environments?
2. Who typically assigns work and how does that authority vary?
3. What does a new worker need to confirm before touching equipment?
4. How do crews distinguish task completion from acceptance/handoff?
5. How is reassignment handled when a task finishes?
6. What does legitimate standby look like versus disappearing or interfering?
7. How do break, meal, show-wait and standby concepts differ operationally and legally?
8. What constitutes actual release from a call?
9. How do timekeeping and clock-out systems vary?
10. Which physical tasks recur strongly enough to justify dedicated teaching versus shared rules embedded across several tasks?
11. Which task methods are truly transferable and which are equipment/manufacturer/employer-specific?
12. Which practicals need field observation rather than knowledge-only assessment?
13. Which skills correlate with increased usefulness, callbacks, department exposure or career progression, and how strong is that evidence?
