# 4. Major architecture findings now supported by evidence

1. **Career progression is a graph, not one ladder.** Technician depth, operator/programmer work, specialist work, leadership, design/engineering and management are often parallel directions.
2. **Early Stagehand work is broad.** Pipe-and-drape, barricades, soft goods, risers/deck support, scenery movement, cases/carts/cable, ordinary tools and dock interfaces are legitimate early-career subject matter when bounded to actual assignment/equipment/authority.
3. **Backline / Props / Wardrobe share an early support interface but split for deeper competency and leadership.**
4. **Stage Management, Production Management, Venue/Event Operations and Crew/Labor Leadership are separate responsibility systems with transfer points.**
5. **One transferable competency graph plus sector overlays is better than duplicating the curriculum for touring, venue, corporate, theatre, worship, broadcast and outdoor work.**
6. **Rigging, energized production power, machinery/automation and hazardous special effects retain explicit external qualification/authorization boundaries.**
7. **Credential semantics must be typed.** Course completion, OSHA Outreach card, observed practice, employer authorization, external certification, license, union/local status and work experience are not interchangeable.
8. **The current website/course structure must not dictate the final knowledge architecture.** Stable content/competency/source/version IDs should survive later presentation changes.

# 5. Current safety / authority posture

The evidence architecture consistently distinguishes:

- `A0` knowledge only;
- `A1` assigned support;
- `A2` observed task state;
- `A3` employer/venue appointment or authorization;
- `A4` qualified/credentialed specialist;
- `A5` licensed/regulatory/AHJ authority.

Crew Blueprint can create learning records and potentially bounded observation records. It cannot itself create A3–A5 status unless a future legitimate external/employer workflow explicitly supplies that separate evidence.

---

# 6. Career / qualification findings

Current source review confirms:

- OSHA 10/30 Outreach cards are course-completion cards, **not certification or licensing**;
- ETCP specialist credentials target experienced entertainment technicians;
- ETCP Arena/Theatre Rigging and Entertainment Electrician/PPDT remain external specialist pathways;
- AVIXA CTS-family credentials are professional AV certifications with continuing-education/renewal requirements;
- manufacturer certificates should remain product/ecosystem specific;
- employer/site task training and authorization remain distinct from all of the above.

These distinctions should later be visible in both the career map and backend profile system.

---

# 7. Learning / backend evidence findings

The future learning system should preserve stable records for:

- content/version viewed;
- knowledge assessment;
- practice preparation;
- observed practice where appropriate;
- employer authorization if externally supplied;
- external credentials/licenses;
- self-reported vs verified work experience;
- content/source/review version lineage.

WCAG 2.2 remains the accessibility baseline. NIST SP 800-63-4 remains a current identity-reference source. 1EdTech Caliper/CLR are interoperability candidates only after Crew Blueprint's own semantics are fixed.
