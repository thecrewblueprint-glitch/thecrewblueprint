# Competency Graph Extension — Stagehand Operational Call Layer

## Why an extension is needed

The existing universal graph contains strong nodes for orientation, assignment receipt, handoff, reassignment, standby/break/release, load-in/load-out literacy, and timekeeping. O01–O08 maps cleanly to those nodes except for one recurring operational capability:

> **working correctly inside a live performance / show-call / changeover rhythm.**

This is not identical to generic standby/release. A worker can understand when they are released and still lack the timing, preset, cue, changeover, performer-route and show-critical awareness required during a running performance.

It is also not identical to load-in/load-out phase literacy.

## New stable competency

### `CMP-CORE-019` — Show-call / changeover rhythm

**Definition:** Recognize that performance/run-of-show work is a distinct operational phase with assigned positions, presets, timing/cue dependencies, performer/public routes, changeovers, waiting states, show-critical equipment boundaries, post-show duties and explicit release/handoff requirements.

**Responsibility baseline:** `R0–R3` depending assigned role.  
**Learning scope:** awareness through assigned-support behavior.  
**Authority:** no cue ownership, stage-management appointment, automation operation, technical-system authority or show-critical decision authority is implied.

### Transfer points

- `CMP-CORE-010` Standby / break / release distinction
- `CMP-CORE-008` Task completion / handoff
- `CMP-CORE-009` Report-back / reassignment
- `CMP-CORE-017` Sector / local-condition adaptability
- `CMP-SMG-*` Stage Management paths
- `CMP-STG-006` cue / preset / changeover scenic workflow
- department show-operation competencies where later defined
