# Superseded Course-Version Review UI

These files preserve earlier owner-review presentation surfaces that mixed old/new comparison navigation. They are retained for lineage only and are not the active review method.

The active review method uses two fully separated spaces:

- `review-current-before-vnext/` — old candidate only.
- `review-vnext-course-set/` — new candidate only.

The neutral gateway is `review-course-version-selection/`.
